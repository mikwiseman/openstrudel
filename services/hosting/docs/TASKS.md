- [x] Production v12, schema 9; 268/268 Linux, полная Mac-проверка 266/266 плюс финальные целевые тесты, бесплатная LIVE проверка Resend + web/native auth. Тестовые сессии закрыты; VM/счетов/списаний нет.

## OpenStrudel — интегрированный Home

Спецификация: `/Users/mikwiseman/Code/openmagic/docs/integrated-cloud-checkout.md`. Чужой репозиторий не редактировать.

- [x] Выданы отдельные sandbox и production ключи для существующего инструмента тестирования с изоляцией аккаунта и сроком действия. Это не credential для распространения в приложении.
- [x] Новая спецификация принята: «Всегда на связи» → владелец → оплата → подготовка → личный вход OpenAI → чат.
- [x] Public client `openstrudel`, authorization code + PKCE S256, точный callback allowlist/state, короткий вход под брендом OpenStrudel. Без общего production ключа и доверия произвольному external_user_id.
- [x] Один вход владельца с восстановлением; без второго пароля/регистрации в кабинете VDS и без аккаунта Kamatera.
- [x] Неизменяемая котировка: профиль/версия/регион/ресурсы, итог/налоги/валюта/точность/срок, продление и возврат, expires_at.
- [x] Заказ с долговечной идемпотентностью и сохранённым согласием на конкретную котировку; восстановление после закрытия/переустановки приложения.
- [x] Раздельные payment_state, session_state, provisioning_state, home_state, action_required. Не предлагать повторную оплату при неизвестном результате.
- [x] Реализована установка разрешённого Home-рецепта по закреплённому SHA256; архив скачан и проверен, установка на новую VM ещё не выполнялась; существующий протокол installationId + P-256 privateKeyPEM + ownerTokenHash. Открытый owner token остаётся у владельца.
- [x] В коде и бесплатных тестах: pinned HTTPS, проверка installation ID и выпуска; VM/SSH ready сами по себе не означают готовый Home. Одна установка и один планировщик. Проверка новой реальной VM остаётся ниже.
- [x] Одноразовый claim, привязанный к владельцу и установке, без секретов в URL/redirect/логах; повтор/другой владелец отвергаются.
- [x] Backend управления из OpenStrudel: статус/срок, явное продление, отмена в конце срока, инструкция ручного SSH экспорта с краткой остановкой Home, IP/SSH/root после повторной авторизации, подтверждённое удаление. Нативный UI внедряет соседний чат.
- [x] Контракт требует личного входа OpenAI на своём Home; чужие токены, runtime и расписания не переносятся. Реальный вход и второе устройство проверяются при живой приёмке.
- [x] Бесплатная приёмка: PKCE/claim replay, неверные callbacks, чужие заказы, восстановление, недоступный тариф/резерв, неизвестная/двойная/поздняя оплата, refund до/после create, неверный TLS pin и достоверная готовность.
- [x] Подготовлены точный OpenAPI v2, fixtures, миграционный rehearsal, runbook (`docs/OPENSTRUDEL.md`); evidence отделяет эмуляцию, бесплатный LIVE API и непроведённую живую приёмку.
- [ ] Реализация native-клиента в openmagic остаётся за чатом OpenStrudel. Полный живой Home требует отдельного бюджета на подходящую VM/платёж. До него не объявлять интеграцию прошедшей production-приёмку.
