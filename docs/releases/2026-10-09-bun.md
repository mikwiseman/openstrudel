# OpenStrudel 1.0 (28): единый образ помощника

Главный помощник использует выбранную улыбающуюся булочку на графитовой плитке.
После проверки в Dock персонаж увеличен примерно на 20%, а внешний размер плитки
сохранён. Строка меню использует монохромную булочку со спиралью и улыбкой;
macOS окрашивает её для светлого и тёмного фона.

Один набор исходников экспортируется для Dock, главного помощника, iOS и веба
командой `swift scripts/export-app-icons.swift`. Старые имена Cream/Graphite
сохранены как совместимые ссылки на новый образ. Источники и размеры описаны
в `native/OpenStrudel/ASSETS.md`.

Перед сборкой выполнен `git pull --ff-only`: включены изменения подключения
удалённых устройств из `5f9c44c`.
