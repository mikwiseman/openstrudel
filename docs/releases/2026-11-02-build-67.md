## Change

Mac uses the standard NavigationSplitView sidebar for Chat and Clients. Client
rows open from their full width, including whitespace, and the same row can open
again after Back. Discuss returns the selected client to the main chat without
losing or sending its draft. Conversation readers open correctly from Clients.
iOS retains its native tabs. Each Home owns its navigation stacks, so switching
Homes cannot leave the previous Home's client detail on screen.

The Mac and iOS client versions are 1.0 (67). The bundled Runtime and public Home
remain build 66, with identical runtime bytes. Android remains build 3. This
client release does not require a Home restart or another backend deployment.
