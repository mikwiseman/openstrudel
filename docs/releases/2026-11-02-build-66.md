## Changes

- The bundled Home includes access-scoped owner source discovery, streamed
  imported history, and the incident lifecycle fixes already tested on the
  current runtime. An unrelated successful turn cannot clear another task's
  failure; task, transcription and delivery recovery remain independent.
- The previously production-only document-signing implementation is now
  reproducible from committed typed source, with its owner, channel, scheduling,
  binding and path checks preserved. This is reconstructed source, not a claim
  that the missing original commit was recovered.
- The Mac build number advances to 66. Native application sources are unchanged
  since build 65. XcodeGen regenerated the project; build inputs and file
  references are unchanged apart from version metadata and generated identifiers.
- A test-only URL protocol explicitly captures its already-Sendable instance in
  its task, as required by Xcode 26.6. No production native UI behavior changed.
