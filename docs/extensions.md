# Сервисы, навыки и плагины

Откройте имя сотрудника → **Сервисы и навыки** → **Добавить сервис или навык**.

- **Сервис** даёт инструменты: вставьте адрес MCP, при необходимости ключ. Статус показывает фактическую связь и число инструментов. Вход через браузер предлагается, если сервер поддерживает OAuth.
- **Навык** объясняет сотруднику, как выполнять задачу. Выберите `SKILL.md` или папку навыка.
- **Плагин Codex** объединяет навыки и подключения. Выберите папку с `plugin.json` или `.codex-plugin/plugin.json`.

Перед установкой показываются название, описание, размер, подключения и наличие автоматических действий. Навыки и плагины можно выключить без удаления. Навык сам по себе не создаёт доступ к внешнему сервису.

## Где это работает

Расширение устанавливается на устройстве сотрудника. iPhone, другой Mac и CLI управляют тем же Home. Сервисы открытого чата настраиваются в его «Сервисах и навыках»; для группы откройте эту группу.

По умолчанию подключение главного чата не выдаётся другим чатам. Владелец может делиться сервисами главного чата со всеми чатами устройства: сотрудниками и группами Telegram, включая новые (`openstrudel services all-chats on`). Тогда MCP-сервисы с собственным ключом и включённые приложения ChatGPT главного чата работают везде, а их отключение в главном чате убирает их и из других чатов. Свои сервисы чата важнее. Если у группы есть сервис с проверенным отправителем Telegram по тому же адресу, используется он, а не ключ владельца. Сервисы со входом OAuth и «Компьютер» остаются в чате, где их подключили. Ими пользуются только люди из списка доступа этого Strudel (`openstrudel access`); остальным участникам группы доступны только сервисы, которые сами проверяют отправителя.

Новые сотрудники имеют отдельные рабочие папки. У старых импортов может сохраниться общая папка: приложение явно показывает число сотрудников, для которых расширение будет общим. Установка не переносит и не переписывает их файлы.

Устанавливать расширения может владелец Home. Участник группы не может установить пакет текстом сообщения. Изменения во время ответа отклоняются до его завершения. Действия инструментов проходят обычное подтверждение.

## CLI

```sh
openstrudel services list --agent AGENT_ID
openstrudel skills preview ./writing-skill --agent AGENT_ID
openstrudel skills install ./writing-skill --agent AGENT_ID
openstrudel plugins install ./writing-plugin --agent AGENT_ID
openstrudel plugins disable 'plugin:writing-plugin@openstrudel-local' --agent AGENT_ID
openstrudel services all-chats on
```

`--chat CHAT_ID` выбирает конкретный личный или групповой чат. `--device DEVICE_ID` направляет команду подключённому устройству. Настройки MCP передаются JSON через stdin, чтобы ключ не попадал в аргументы процесса:

```sh
openstrudel services add documents --agent AGENT_ID < private-mcp-config.json
```

Файл содержит `url` и необязательный `token`. Для локальной программы CLI также принимает `command`, `args`, `env`. Для удалённых адресов требуется HTTPS. Пользовательские секреты не выводятся в списке подключений.

Для сервиса с собственным заголовком авторизации JSON также принимает `http_headers`, например `{"X-API-KEY":"<private key>"}`, и `disabled_tools`, например `["execute_request"]`. Передавайте такой JSON через stdin из приватного файла, а не в аргументах команды. Заголовки протокола и проверенной личности, повторяющиеся имена без учёта регистра и управляющие символы отклоняются. `token` и собственный `Authorization` нельзя задавать одновременно. Секретные значения сохраняются в файлах с правами `0600` и не возвращаются в результате установки.

Выбор «во всех чатах» может содержать исключения `ownerOnlyServers` в существующем `.data/extensions/all-chats.json`. Имена из этого списка не наследуются сотрудниками и группами, включая новые; обычное выключение и включение общего доступа сохраняет список. Повреждённые настройки закрывают наследование. Сначала сохраните исключение, затем подключайте личный сервис. Это ограничение наследования не меняет отдельное подключение, которое владелец явно установил в другом чате. Для Unipile нужен также проверенный список аккаунтов и отключение общего инструмента запросов: [личные источники и черновики](cross-channel-intelligence.md).

## Реализация

Используются штатные возможности Codex: `skills/list`, `skills/config/write`, `config/mcpServer/reload` и CLI `codex plugin`. Предварительные plugin RPC не используются. Конфигурация расширений принадлежит аудитории и сохраняется при смене подписки; плагин регистрируется штатным CLI в новом `CODEX_HOME`. Коллекция плагинов личного аккаунта не импортируется в группы автоматически.

Пакеты ограничены 300 файлами и 10 МиБ. Символические ссылки, выход за каталог и конфликтующие имена отклоняются. Установка проверяет хеш предварительного просмотра; при неудачной перезагрузке настройки и файлы откатываются. Первая версия поддерживает локальные пакеты и MCP-адреса, без отдельного магазина и установки архивов по URL.

Источники: [Codex plugins](https://developers.openai.com/plugins/build/plugins), [App Server](https://learn.chatgpt.com/docs/app-server#api-overview).
