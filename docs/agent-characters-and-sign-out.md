# Образы сотрудников и выход на устройстве

Mac 1.0 (14), iOS 1.0 (16), Home 1.0-14.

## Образы

У каждого сотрудника один из шести персонажей: завиток, конвертик, узелок,
рогалик, волна или подушечка. Восемь цветов дают 48 сочетаний. Кнопка «Другой»
выбирает другое сочетание; форму и цвет можно выбрать отдельно. Образ меняется
в настройках сотрудника, при создании он выбирается заранее. Основной собеседник
OpenStrudel сохраняет знак штруделя.

Существующим сотрудникам образ назначается одинаково на всех клиентах по их ID.
Переименование его не меняет. Выбор сохраняется на устройстве сотрудника и входит
в экспорт. При импорте с новым ID сохраняется исходный образ. Внешность не меняет
инструкции, модель или доступы сотрудника. Картинки поставляются с приложением;
для их отображения не требуется генерация или отдельный сетевой сервис.

API передаёт `appearance: {version: 1, kind, tone}`. Home сообщает поддержку через
`agentAppearanceVersion: 1`. Изменение образа на старом исполнителе требует его
обновления; клиент проверяет, что сервер действительно сохранил выбор.

## Выход

В настройках команды есть «Выйти на этом устройстве». Подтверждение объясняет,
что агенты, история, файлы и расписания остаются там, где работает команда.
Выход отключает только клиент. Он не останавливает Home, задачи, другие устройства
или вход владельца в OpenAI. Команда работает, пока её Mac или сервер включён.

Владелец может выбрать «Сохранить копию и выйти». Сначала обновляется список
устройств, затем для каждого готовится отдельный `.openstrudel`, включая устройство
без дополнительных сотрудников: на нём может быть история основного собеседника.
Если хотя бы одно устройство недоступно или сохранение отменено, клиент остаётся
подключённым. На Mac и iOS выход выполняется только после успешного сохранения
всех файлов системным диалогом. В браузере файлы скачиваются отдельно, затем
пользователь нажимает «Выйти»: браузер не подтверждает запись файла на диск.

Экспорт содержит сотрудников, инструкции, настройки, переписку, вложения,
рабочие файлы и расписания. Доступы к OpenAI и подключённым сервисам не входят.
При импорте сотрудники добавляются, существующие сохраняются; импортированные
расписания остаются на паузе.

Удалённый клиент отзывает только своё приглашение через `/auth/device/logout`.
При отсутствии сети локальное подключение всё равно удаляется. Локальный Home
сохраняет служебный токен. Нативное приложение запоминает выход и после перезапуска
не подключается автоматически. Возврат на исходном Mac: «На этом Mac»; удалённому
клиенту нужно новое приглашение. Неотправленные сообщения и черновики сохраняются
локально для повторного подключения к той же команде.

## Проверки

Регрессионные тесты проверяют совместимость старой БД и архивов, сохранение образа,
отклонение некорректных значений, отзыв только текущего клиента, выход без сети,
сохранение состояния выхода и защиту от запоздалого восстановления подключения.
UI-сценарий проходит выбор образа, сохранение, повторное открытие, отмену выхода,
подтверждение выхода и повторный запуск. Частные протоколы испытаний хранятся
в `.data/agent-characters-2026-10-06/`; в репозиторий не включаются личные данные.
