# Простое облако OpenStrudel

Состояние на 5 октября 2026 года: интерактивная спецификация, проверки PoC и проверенный адаптер к эмулятору WAI VDS. Это ещё не опубликованный способ покупки. VDS-сервис разрабатывается отдельно; DigitalOcean продолжает работать в текущем приложении.

## Что видит человек

Основной путь: «Ваша команда. Всегда на связи» → окончательная цена и условия → защищённая оплата → подготовка команды → личное подключение OpenAI → чат. Слова VPS, VDS, SSH, root, cloud-init и выбор CPU не нужны для прохождения этого пути.

Рекомендуем размещение автоматически по проверенному профилю и наличию мощности. Название инфраструктурного провайдера, регион, характеристики, полный доступ и самостоятельный DigitalOcean находятся в дополнительных настройках. Выбор другого провайдера или новой цены требует нового подтверждения; незаметно переносить заказ нельзя.

Цена, срок, налоги и условия продления показываются до оплаты. Автоматическое продление по умолчанию выключено. Если платёж отклонён, человек возвращается к оплате; если статус ещё неизвестен, он проверяет существующий заказ. Эти состояния имеют разные действия.

Прогресс отражает подтверждённые этапы: оплата, создание, установка, проверка подключения. Нет выдуманных процентов и гарантии «за минуту». При задержке человек видит, что сохранено и как продолжить. Возврат из браузера не означает успешную оплату.

Полный доступ остаётся у владельца: адрес, SSH-ключ, инструкции экспорта и завершения размещения доступны после повторной проверки его личности. Закрытие приложения и остановка VM не равны прекращению оплаты. Отмена продления сохраняет работу до конца оплаченного срока. Удаление требует отдельного явного подтверждения.

## Ответственность компонентов

| Компонент | За что отвечает |
| --- | --- |
| OpenStrudel | Понятный интерфейс, собственный ключ устройства, сохранение идентификатора заказа, проверка состояния, TLS pin готового Home, приглашения других устройств. |
| VDS-сервис | Аккаунт покупателя, hosted checkout, окончательная котировка, проверенный webhook, журнал операций, идемпотентность, установка, продление, возвраты, удаление и поддержка. |
| Провайдер | Выдача виртуальной машины, сеть, фактическая тарификация и инфраструктурные операции. Его общий ключ не попадает в клиентское приложение. |
| Home | Выполнение агентов, история, расписания и единственная авторизация OpenAI. Он не получает платёжную карту или общий ключ провайдера. |

Покупатель получает контроль над своей VM. Инфраструктурный аккаунт оператора остаётся у оператора. Передачу VM в личный аккаунт провайдера нельзя обещать без подтверждённой процедуры.

## Связь с WAI VDS

VDS-сервис ведётся в отдельном репозитории и чате «WAI VDS — сервер в один клик».

API v1 содержит `/api/v1/catalog`, `/api/v1/orders`, статусы серверов и операции доступа/продления/отмены. 5 октября проверены реальные HTTP-ответы локального эмулятора с выделенным ключом: выдача одного учебного сервера, повтор запроса без дубликата, восстановление, отмена и удаление. В отдельной модели проверен перезапуск клиента после потерянного ответа на создание. Код и границы проверки: [адаптер WAI VDS](../poc/wai-vds/README.md).

Публичный сервис `https://pay.waiwai.is/vds/` отвечает и использует Kamatera / WAI Pay; checkout закрыт до инфраструктурной приёмки. Бесплатное чтение его каталога не подтверждает выдачу VM или оплату. Тестовый `/agent/servers` обходит checkout через явный `sandbox_grant`, поэтому проверка этого пути не считается проверкой платежей.

На момент чтения исходников стартовый общий профиль сервиса был 2 GiB RAM / 20 GB. Для первого проверяемого профиля OpenStrudel выбран минимум 4 GiB RAM / 30 GB и публичный IPv4. Общий дешёвый VDS-тариф не должен автоматически становиться тарифом OpenStrudel. `poc/cloud-onboarding/eligibility.mjs` проверяет эту границу. Прохождение проверки ресурсов не означает готовность к продажам.

В текущем контракте назначение `agent` устанавливает Docker; оно не устанавливает Home и не меняет ресурсы тарифа. Сервис ещё не возвращает готовое HTTPS-подключение Home, TLS pin и одноразовую привязку владельца. Ключ тестового аккаунта не предназначен для включения в нативную сборку. Эти ограничения блокируют публикацию нового способа размещения.

До подключения нужны:

1. Согласованная котировка для назначения OpenStrudel: ресурсы, реальная доступность региона, полная цена и срок, режим платежей, правила отмены и возврата.
2. Долговечный заказ с уникальным ключом попытки. Создание VM фиксируется до запроса провайдеру; неизвестный результат сверяется, а не повторяется вслепую. Приложение может только читать его состояние после потери связи.
3. Установка проверенного Home-артефакта с закреплённым SHA256. Ключ устройства и приглашение принадлежат конкретной установке. Нельзя использовать чужую глобальную авторизацию Codex или запускать второй runtime/расписания.
4. Готовность означает работающий HTTPS Home с ожидаемой TLS-идентичностью и завершённой установкой. Статусы `VM running` и `SSH open` недостаточны.
5. Обработчик платформенной авторизации клиента: не вставка общего провайдерского токена в приложение. Для iOS отдельно проверяется допустимый способ покупки и связь с учётной записью; готовый web-checkout не является основанием для безусловной кнопки внешней оплаты во всех storefront.

Проверка готовности отдельного чата настроена раз в час в текущем чате; при отсутствии изменений она не создаёт повторные отчёты. После принятия API и появления разрешённого тестового бюджета запускается интеграционная проверка. Эта автоматизация не создаёт облачные ресурсы сама по истечении времени.

## OpenAI и подключённые устройства

Сохраняется [существующая модель одного аккаунта на Home](account-lifecycle.md). Только владелец начинает вход и лично подтверждает его на официальном сайте OpenAI. Обычный подключённый клиент видит состояние и ждёт владельца; он не получает OAuth-ключи.

Истечение авторизации отличается от потери связи с Home и от отозванного приглашения устройства. Восстановление OpenAI не удаляет историю и не создаёт новую VM. Пришедший из OpenAI отказ не должен выглядеть как `workspace routing discovery unauthorized (401)`. Прерванную задачу с возможными внешними действиями нельзя автоматически повторять после входа.

## Приёмка перед публикацией

| Область | Проверка |
| --- | --- |
| Новый пользователь | Аккаунт, окончательная цена, согласие на продление, оплата, установка, личный вход OpenAI, первый настоящий ответ. |
| Оплата | Отмена, отказ, задержка, фальшивый/повторный webhook, другая сумма/валюта/учётная запись, успех браузерного redirect без webhook. |
| Выдача | Нет мощности, нехватка баланса оператора, timeout до/после создания, перезапуск процесса, дубликат запроса, несовпадающая TLS-идентичность. |
| Возврат к работе | Закрытие и повторное открытие приложения на каждом шаге; сохранение существующего заказа; черновики, offline, повторное подключение. |
| Авторизация | Отмена, просроченный код, запрет device-code, повторный вход того же владельца, смена аккаунта, отзыв доступа, ожидание обычного участника. |
| Другие устройства | Mac и iOS подключаются по приглашению к одному Home, без второй авторизации OpenAI; отозванное приглашение не затрагивает оплату. |
| Жизненный цикл | Перезагрузка VM и повторное подключение, повторный старт ровно одного Home и расписаний, продление, отмена в конце периода, просрочка, экспорт, подтверждённое удаление. |
| Изоляция | Пользователь не видит заказы и ключи другого; сырой пароль/токен не появляется в UI, логах, исключениях или аналитике. |
| Интерфейс | Маленький экран, горизонтальное положение, светлая/тёмная тема, крупный текст, клавиатура, VoiceOver, отсутствие обрезанных ошибок. |

Абсолютно все сочетания внешних сбоев нельзя перечислить. Приёмка ведётся по этой явной матрице, критическим инвариантам и воспроизводимым доказательствам. Неизвестные или заблокированные проверки не считаются пройденными.

## Проверяемый прототип

```sh
node poc/cloud-onboarding/serve.mjs
node --test poc/cloud-onboarding/*.test.mjs poc/eqvps/provider.test.mjs poc/wai-vds/*.test.mjs
node poc/eqvps/probe.mjs
node poc/cloud-onboarding/preflight.mjs --base-url http://127.0.0.1:4781
```

Сервер предпросмотра слушает только `127.0.0.1` на свободном порту, напечатанном при запуске. Не запускает Home, задания или платные операции. В интерфейсе постоянно видна пометка «Прототип», все цены и заказы демонстрационные. Политика CSP запрещает сетевые обращения из страницы. Кнопки операций с настоящей VM объясняют отсутствие реального сервера, а не имитируют успешную выдачу ключа или экспорт.

Модель интерфейса — исполняемая спецификация, не production-база заказов. В частности, повреждение локального хранилища в прототипе сбрасывает демонстрацию; production-клиент в такой ситуации обязан восстановить заказ по аккаунту с сервиса, прежде чем разрешать новую покупку.
