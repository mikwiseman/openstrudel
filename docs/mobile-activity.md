The iPhone and iPad use three native tabs. Chat remains the only composer and continues to route requests through the selected Home's main assistant. Insights is a reader for scheduled results and unresolved incidents. Progress shows retained request and automation facts, account limits, and a direct Clients entry in its toolbar. The Mac retains the accepted build 67 Chat / Clients split view.

## Real data and source boundaries

`HomeClient.readActivity()` reads the owner-only `GET /v1/activity` for the selected Home. The native decoder preserves the agreed envelope: `checkedAt`, `period`, sourced `insights`, and `progress`. It does not derive completion from message prose or invent outcomes. The backend's counts cover today and the preceding six dates in the owner's reported timezone; highlights cover thirty local dates, capped at thirty. First request and first automation milestones come from lifetime retained receipts; three active days is a seven-day milestone.

The main figures are answered requests, nonquiet automation results and active days. Quiet runs and failures are separate. These are task receipts, not evidence of business acceptance, revenue or time saved. The character acknowledges the first request/automation with a restrained pose and an accessible sentence. There is no spending reward, streak penalty, new ledger or idle animation. Reduce Motion disables the transition; accessibility text sizes stack the character above its caption.

Each insight opens its actual source conversation. Discuss is available only when the Home provides a message ID. It attaches that message and conversation identity to the existing Chat draft, without sending and without substituting the preview text for source evidence. The Home re-reads its own message when the user eventually sends. Safe generic incidents without a visible message can still open their source conversation. News readers remain available from Insights and from the existing history picker.

Limits come separately from the existing `/v1/accounts` API, using the established usage display. A missing limit remains unknown. Refresh failures clear account balances. Activity loads on tab entry and manual refresh, with no additional background polling. Generation and Home identity checks discard late responses. A Home change clears detail paths and cached activity; 403/401 clears private activity, and 404 explains that the Home needs an update. Same-Home offline activity is explicitly labelled as the last checked copy. No other Home's cache is used as a fallback.
