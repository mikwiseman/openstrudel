# Приёмка прототипа простого облака

Дата: 4 октября 2026. Область: интерфейс, исполняемая спецификация переходов, бесплатный провайдерский probe, предварительная совместимость с отдельным VDS-сервисом. Нативные приложения и опубликованные сборки этим PoC не изменены.

## Проверено

| Проверка | Результат |
| --- | --- |
| Модель потока | 16 тестов PASS: возврат из checkout не выдаёт VM; согласие OpenAI не обходится; неизвестный результат не создаёт повторный заказ; восстановление после offline/истечения входа; отмена; участник без прав владельца; просроченный код; различие между pairing и OpenAI. |
| Совместимость VDS-каталога | 3 теста PASS: память, диск, публичный IPv4, корректная котировка, отсутствие автоматического допуска к продажам по одним характеристикам. |
| EQVPS | 14 тестов PASS: NAT и неподходящие тарифы, месячная цена, роли API, JSON/SSE и pagination, timeout без повтора, запрет платного fallback, приватный файл ключа, отсутствие секретов в выводе. |
| Браузер | 21 состояние × 3 viewport × 2 темы × 2 размера текста = 252 проверки. Ни одного горизонтального переполнения, отсутствующего заголовка или видимой кнопки/summary меньше 44 px. |
| Размеры | 375×812, 667×375, 1024×768 CSS px. Дополнительно просмотр отдельной колонки 375 px. |
| Контраст текста | Светлая тема: основной 14.85:1, вторичный 6.02:1, кнопка 15.08:1. Тёмная: 14.81:1, 8.53:1, 11.99:1. |
| Клавиатура | После переключения согласия фокус остаётся на checkbox; следующий Tab попадает на оплату. Явная рамка фокуса, все действия имеют текст. |
| Возврат в приложение | Путь оплата → подготовка → личный вход → готово пройден. Повторное открытие сохраняет готовый и неизвестный заказ. |
| Права участника | Нет кнопки входа в OpenAI и получения root-ключа; после входа владельца открывается команда. |
| Отмена продления | Явное согласие включает продление; отмена сохраняет готовую команду и переводит UI в состояние завершения оплаченного периода. |
| Ошибки JavaScript | Не обнаружены в браузерном прогоне. |
| EQVPS, настоящий публичный API | Каталог и MCP `tools/list` ответили. Найден профиль 4 GiB / 40 GB / dedicated IPv4 / Ubuntu 24.04 по публичной розничной цене $15/месяц; это не оптовая котировка или обещание наличия мощности. Партнёрская схема без ключа не видна. |
| VDS, настоящий локальный API | `/healthz` и `/api/v1/catalog` ответили на документированном локальном адресе. Текущий общий профиль 2 GiB / 20 GB не принят для OpenStrudel; provider и payments — эмуляторы. |

Интерактивные проверки проводились через Codex in-app browser. Смена размера текста здесь — CSS-моделирование; это не проверка iOS Dynamic Type на физическом устройстве. Отключение анимации включено в прогоне. Нативный VoiceOver и фактический системный Reduce Motion должны проверяться при переносе интерфейса в SwiftUI.

## Что остаётся непроверенным

- Партнёрские методы EQVPS и provider-side `test:true`: аккаунт оператора пока не создан, ключ не предоставлен.
- Настоящая оплата, проверенный налог и окончательная цена покупателю.
- Живая VM выбранного тарифа, установка Home, SSH/TLS, OpenAI владельца именно на этой VM, второе устройство, перезагрузка, повторное подключение и удаление.
- Production-восстановление заказов из базы сервиса: модель UI и localStorage не заменяют его.
- Весь клиентский путь аккаунт → checkout → API заказа в публикуемой нативной сборке, включая правила платформы iOS.

До этих проверок режим не объявляется готовым к продаже и не публикуется в нативном приложении. Новые платные операции не выполнены; старый лимит DigitalOcean не использован повторно.
