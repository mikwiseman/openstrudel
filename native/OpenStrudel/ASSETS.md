# OpenStrudel visual assets

`OpenStrudelMark.png` and the app icon variants are derived from an original
AI-generated OpenStrudel brand mark.

Prompt: “Create a premium app icon asset for an AI assistant called OpenStrudel.
Square, no text or letters, transparent background, a single abstract folded
ribbon / strudel swirl forming a soft four-point star, calm indigo-to-lilac
glass gradient, subtle inner glow, tiny specular highlight, dark-mode native
macOS and iOS aesthetic, refined and quiet, geometric, legible at 20px, no
generic sparkle icon, no mascot, no UI, centered with generous breathing room.”

The source was generated with the available OpenStrudel image-generation
tool, then resized only for Apple asset-catalog slots.
