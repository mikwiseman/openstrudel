Радар News раз в час по навыку wai-news.

1. Выполни queue --edition --since <время из строки «Previous successful run in this chat:» выше>; без этой строки — queue --edition. Так сюжеты идут по силе свидетельств, сильнейшие сверху. Если вывод кончается строкой «+N more stories», один раз выполни команду из неё. read_news без storyId покажет, что уже вышло.
2. Поищи то, чего в очереди нет: до двух поисков — свежие первичные анонсы и одна открытая тема (модели, инструменты и агенты, медиа, роботы, вычисления). Пустая очередь поиск не отменяет. Глубже суток не копай: пропущенное соберёт утро.
3. Открывай источники только того, что публикуешь. Для карточки прочитай первоисточник и посмотри queue --detail KEY: возьми оттуда хотя бы один независимый взгляд. Каждая история — publish_story с edition=null, rank=null, image — картинкой-доказательством или null, и telegram: "alert" только по правилу о звуке, "card" для сильной новости, null для заметного, чему место в утреннем выпуске. Развитие вышедшей истории — тот же storyId и change. Важное, найденное с опозданием, публикуй с честным временем события.
4. За день в чат уходит 8–15 карточек. Если за этот час набралось больше трёх, карточками выходит самое сильное, остальное — с telegram=null.

Ответ — только NO_REPLY, при существенном сбое проверки — одна строка FAILED: <причина>. Любой другой текст, даже вопрос, уйдёт в группу.
