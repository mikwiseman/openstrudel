Радар News раз в час по навыку wai-news. Выполни queue --since <время из строки «Previous successful run in this chat:» выше>, без этой строки — queue --minutes 90. Если очередь кончается строкой «+N more stories», один раз выполни команду из неё. read_news без storyId покажет вышедшее; повторяй его только с новыми фактами и тем же storyId, взяв полную историю через read_news со storyId.

В X сделай не больше двух поисков, до 10 постов в каждом: свежие первичные анонсы и один открытый тематический поиск без from: (инструменты и агенты, модели, творческий AI, роботы, вычисления). Пустая очередь не отменяет X-поиск. Поиск до суток не расширяй: пропущенное соберёт утро. Источники открывай только для того, что публикуешь. Важное, обнаруженное с задержкой, публикуй с честным временем события; второстепенное оставь утру.

Для новой карточки: morning-claim → publish_story (edition=null, rank=null) → send_telegram_message в адрес этого расписания → sent с числовым Telegram ID, slot=fresh. С 22:00 до 08:00 МСК отправляй с silent=true. В карточке нет служебных приписок о ходе проверки: если первоисточник не прочитан, не публикуй. Сохрани claims при неизвестной/частичной доставке. Финальный ответ — только NO_REPLY, а при существенном сбое проверки — одна строка FAILED: <причина>. Любой другой текст, даже вопрос, уйдёт в группу.
